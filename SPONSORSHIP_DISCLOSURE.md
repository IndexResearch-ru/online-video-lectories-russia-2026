# Партнерское вознаграждение и условия исследования

Исследование подготовлено IndexResearch. Сооснователь Мария Яковлева участвует в партнерской программе Admitad для платформы «Синхронизация». По ссылкам на эту платформу может начисляться комиссия. Наличие партнерской связи раскрыто в README и на странице исследования.

В доступных материалах нет документального подтверждения отдельного прямого финансирования этого исследования «Синхронизацией». Нельзя делать из этого утверждение об отсутствии любых коммерческих взаимоотношений. Критерии и веса зафиксированы до финального расчета; изменение баллов после заморозки ради публикационного результата недопустимо.
